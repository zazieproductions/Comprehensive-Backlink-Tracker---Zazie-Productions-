# 🖤 SPAM, SCRAPER, SYNDICATION, SEO-POISONING & LOW-TRUST MENTIONS — register

> **Purpose.** Locate and document *public pages that visibly contain the exact string*
> `"Zazie Productions"` or `"Zazie Kanwar-Torge"` but appear to be low-trust, spam-like,
> scraped, autogenerated, SEO-manipulation, RSS-republication, content-farm, doorway-page,
> hacked-site, malformed-directory, search-redirect, or unexplained text-injection occurrences.
> This is an **evidence-preservation and provenance** category — **not** a promotion, outreach,
> interaction, or amplification task.

---

## 1. What this register is (and is not)

- **It is** a quarantine shelf: every occurrence of the two exact target strings that looks like
  a trace of scraping, syndication, indexing contamination, automated copying, or unwanted
  association is recorded *here* so it can never be mistaken for a real credit.
- **It is not** a source of truth. Nothing in this category ever counts as: credible editorial
  coverage · a verified career credit · a legitimate artist profile · a valid music release ·
  an official business presence · a meaningful press mention · a trustworthy source of
  biographical information. Even where the page is a genuine public occurrence of the exact
  phrase, it is **flagged D** in `data/master/master_index.csv` and excluded from
  authority-weighted totals.
- Pre-existing instances elsewhere in the repo (the old `SEO Spam / Link Farm` rows, the Tier-D
  `Video Mirror / Backlink Sites` cluster, the dump's "spam sites" block, and the seed's
  "Suspected spam / SEO parasite pages" cluster) were **folded into this register** on
  2026-09-05 — see `LOWTRUST_REGISTER.md` §"Reclassification".

## 3. Search rules (unchanged from the master brief)

- Search **only** the two exact quoted strings: `"Zazie Productions"`, `"Zazie Kanwar-Torge"`.
  No spelling variants, partial names, aliases, generic “Zazie”, fuzzy matches, transliterations,
  or inferred identities. Every query preserves one complete quoted exact target phrase.
- Record only **publicly accessible** material.

## 4. Safety protocol (mandatory for every agent touching this category)

1. **Read only.** Do not submit forms, create accounts, click advertisements, follow suspicious
   downloads, execute scripts, or interact with page elements beyond what is necessary to read
   publicly visible text.
2. **No bypassing.** Do not bypass CAPTCHAs, authentication, paywalls, robots rules, rate
   limits, or bot protections. A page behind an unsolved challenge is logged as ⬜ blocked.
3. **Host quarantine.** Hosts identified as malware-distributing or compromise-served
   (e.g. `vidmak.com`, `powerkabel.com.pe`, `wnloveet.click`, and the injected-path news portals)
   are **documented but never visited**. Their state is established from the dump record,
   search-index snippets, and archive metadata APIs only.
4. **No amplification.** Never link these pages in outward-facing summaries, never "contact"
   them, never request removal *through* interaction with the spam surface itself.
5. **No trust transfer.** Claims *on* a low-trust page (bios, awards, quotes) are void for the
   census; several entries here contain fabricated attributions (see `PASTE-REPUB` cluster).

## 5. Subtype taxonomy (the `Subtype` column)

| Subtype | Meaning |
|---|---|
| `DOORWAY-INJECT` | Injected doorway page on a hacked/unrelated host (the BMC/IRLAM slug template). |
| `SPAM-SHOP` | Spam shop / malware-adjacent product page riding scraped keywords. |
| `MISATTRIB-FLAG` | Dump-flagged "spam site" whose page belongs to an unrelated entity; no exact-name occurrence established — never countable at all. |
| `TOOL-MIRROR` / `EMBED-CANONICAL` | YouTube player-mirror tool that scrapes the video metadata (name appears via the scraped title/channel only). |
| `INJECTED-EMBED` | Embed path injected onto a legitimate third-party site (news portal, school site, etc.). |
| `TYPOSQUAT-MIRROR` / `SUSPICIOUS-MIRROR` | Typosquatted or scam-adjacent mirror hosts. |
| `TOOL-PROFILE-MIRROR` | Mirror of a platform *profile* (not just a video). |
| `PIRATE-SCRAPE` | Pirate "listen/download" index auto-populated from streaming metadata. |
| `AUTOGEN-METADATA` | Machine-written stats/credits/lyrics pages cloned from platform APIs. |
| `AUTOGEN-SEARCHURL` | The record is itself a search-query URL, not a stable page. |
| `PAYTOPLAY-DIRECTORY` | Pay-to-play promo/chart directory (listing implies payment, not endorsement). |
| `FABRICATED-ATTRIB` | Paste hosting auto-generated or persona-fiction essay with invented experts/journals. |
| `PASTE-REPUB` | Anonymous pastebin republication (PR text, dumps); now often deleted. |
| `RSS-SYNDICATION` / `PR-FEED-REPUB` / `AUTO-AGGREGATOR` | Feed/scrape re-publishers; content is carried, not authored. |
| `LEGACY-MIRROR` / `SYNDICATION-MIRROR` | Dead or surviving mirror sites re-publishing an original (reddit proxy, wiki mirrors, Medium mirror). |
| `BOT-UGC` | Bot-like social re-posting. |
| `SEARCH-REDIRECT` / `SERP-ARTIFACT` | Redirect wrappers or Google-CSE tab artifacts indexed with the name. |
| `PLATFORM-REPUB` / `KEPT-BORDERLINE` / `REVIEW-KEPT` | Reviewed surfaces kept where they are (register records the judgment). |

## 6. Evidence levels (same three gates as `docs/01` §5)

`verified` (opened page, exact string read) · `search-index verified` (index snippet preserves
the string) · `verified-partial` / `unverified` / `broken` / `blocked` / `not-probed-safety`.
**A "hit" in this category documents that an occurrence exists (or existed) — it is never
counted in authority-weighted totals.**

## 7. Adding a row (append-only)

1. Add to `lowtrust_ledger.csv` (next `LT-###`) **and** to `data/master/master_index.csv`
   under category `Spam, Scraper, Syndication, SEO-Poisoning & Low-Trust`, tier `D`.
   Register-only borderline records skip the master.
2. Set `status` per §6; record the exact snippet; log the query in `queries_run.csv` and every
   read/refusal in `source_access_log.csv`.
3. Run `python3 scripts/generate_docs.py`.
