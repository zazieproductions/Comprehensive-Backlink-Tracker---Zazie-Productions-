### Final Publication-Feature Summary and Discovery Analysis

#### Which kinds of magazines, zines, journals, blogs, or editorial sources produced the strongest results

- **Independent music webzines/magazines** produced the *strongest and most verifiable* Tier A results: **Indie AM** (Mexico), **Shock Web Radio** (LatAm), **Soundsgood Webzine** (Italy), **HEAVY Magazine** (AU/intl), **Pop Fantasma** (Brazil, Tier B roundup). These are exactly the “independent music, experimental-culture, sound-art, avant-garde, local-arts, or DIY publication” family described in the qualifying-content list. Each had a headline that *is* the exact phrase, a body that profiles the single, and a tag archive confirming editorial indexing. All were verified live at HTML level.
- **Arts-literary magazines / journals** produced the next strongest: **Superpresent Magazine** (ISSN journal, print + PDF) and **Ranger Magazine** (music/lit/art periodical) both gave *contributor/feature pages* with audio embeds and linked issue contents indexes. These were verified via **PDF + HTML issue indexes** — the strongest publication-type evidence because they are paginated, edited, and ISSN-indexed.
- **Cultural-institution publications** produced a durable Tier A: **Black Mountain College Museum + Arts Center** (commissioned radio-artist profile). This is the sole institutional-journal host in the feature set and it survived live verification with two exact-phrase hits plus a broadcast context.
- **Industry/design/Pulitzer-type journals** produced the sole *by-target* Tier A: **Pulitzer Center** (letter as published writing). This is the only literary-journal-style *essay by* the target that is publicly HTML-verifiable. The other literary claims (Bipolar, Milkweed, Blastbones, Barb, Church of Malware) remain high-value but *unverified* this pass.
- **Blogs that look magazine-like but did not meet threshold:** **Casey Douglass** (horror/ambient blog, Blogger) was a good example of a music blog that *did* contain the exact phrase but only as a 1-of-20 track-list entry — not substantial coverage. It was demoted from master’s B to Tier C under this stricter definition, illustrating the value of the explicit editorial-relevance tier system.

#### Whether newly found features were concentrated in any category

- **No newly found (novel-URL) Tier A/B features were concentrated anywhere — because none were found.** The 7 broad queries + 30 site-restricted + 16 PDF + 15 archive checks all returned either (a) visibility of the same 19 URLs already in the master/seed, (b) no exact phrase on destination, or (c) deferred zine/journal claims where interior pages were not publicly HTML-visible.  
- **Reclassified, not new:** The only “new to the feature table” entry was **Soundsgood Webzine** — but it was *not* new to the overall dataset; it was already in the 260-URL seed dump (and therefore discovered before this pass). Its novelty is *reclassification* from seed-only listing to Tier A feature after page-level verification (Italian review). Category-wise, that is **music webzine** — consistent with the concentration above — but it does not represent a new category discovery.  
- **If the 5 unresolved zine/journal leads (Coin-Operated, Bipolar, Milkweed, Church of Malware, 100Subtexts-type) were verified**, the concentration would shift toward **literary zines / small-press journals / community codex** — i.e., *literary writing* and *experimental-culture theory*, not music.

#### Whether Yahoo, Brave, Marginalia, archives, direct publication searches, RSS feeds, PDFs, or another source type produced unique qualifying features

- **Yahoo / Brave / Marginalia (prioritized per brief):** Deep paging (pages 1-5) was reviewed specifically for long-tail indie magazines, older blogs, HTML publications, low-traffic journals, defunct zines, archive pages, static sites. Result: **No unique qualifying feature** beyond those already found via general web + direct fetch. Brave and Marginalia both returned the same **Superpresent/HEAVY/Ranger** bios and the **Coin-Operated Press call pages**, but those are either already-counted or below-threshold. Marginalia’s bias toward old/indie/non-commercial web did surface the **WordPress.com Coin-Operated** host more prominently, but without phrase-visible interior content it remained a lead, not a feature. Yahoo’s aggregated view did not add a URL beyond the Bing/Google pool for this query set.
- **Archives (Wayback, archive.today, archive.ph, archive.is, Memento):** No *archived-only* feature was counted. Checks for Grammy Weekly, HEAVY, and the four magazine PDFs showed either *no capture* or *capture identical to live* — therefore correctly **not counted as a separate feature** per spec (“do not count an archive capture as a separate feature if it simply preserves the same content already represented by a verified live canonical page”). The single PDF that matters (Superpresent) is *live at origin*, so the archive is supplementary.
- **Direct publication-site searches (RSS/Atom, sitemaps, issue indexes, author archives, category/tag archives, site-search):** For the 7 magazine domains fetched directly, **no additional page beyond the 19 canonicals** was found. RSS feeds for Indie AM, Shock Web Radio, Soundsgood, and Ranger contained only the already-counted feature entry (plus unrelated new posts). Sitemaps enumerated hundreds of URLs but none with a `zazie` path beyond the one feature per domain. Author archives (Alejandro Balcázar, Ethan Walker) did not disclose a second target feature. In that sense, the direct-site method **confirmed completeness** for those domains rather than adding new features — a valuable *negative-result* signal.
- **PDFs:** The only PDF that yielded a qualifying feature was **Superpresent’s V4N3 PDF**, which was already in the master and seed. No new zine PDF with phrase-visible interior was surfaced via `filetype:pdf` — confirming that the still-unverified zine claims (Coin-Operated interior, Codex) are not currently indexed as public PDFs, or are print-only.
- **Summary:** The unique-source-type that *did* produce the strongest *verification* (not discovery) was **direct PDF fetch + issue-index fetch** — i.e., fetching the PDF text layer and the issue contents HTML gave page-number evidence (`p.66`) that search snippets alone cannot provide.

#### Whether any results were only apparent features but were excluded after page-level review

- **Yes — several apparent features were excluded after opening the destination page and checking for substantial editorial content (Tier C/D). Examples:**
  - **Casey Douglass — Dark Ambient: Shadowlands 4** looked like a music-magazine feature from snippet (`Dark Ambient: Shadowlands 4 Is Out Now!` + `Zazie Productions`), but page-level fetch shows the exact phrase appears only once in a 20-track embed tracklist, with no paragraph about the target — excluded as Tier C.
  - **SoundBetter — Interview with Zazie Productions** looked like a Q&A feature (`Interview with Zazie Productions` appears in snippet for `“Zazie Productions” interview`), but page-level review shows it is a *service-marketplace profile* with a self-published Q&A block — excluded as Tier D (not an independent magazine).
  - **Rock Culture — Noticias line** snippet suggests a news feature, but the headline is a comma-separated list of ~8 artists; target appears without dedicated paragraph — excluded as Tier C passing mention.
  - **Tinnitist — tag page** snippet suggests a tag archive; page-level is automated tag listing — excluded as Tier D.
  - **Coin-Operated Press announcement pages** snippet suggests a zine feature, but the fetched announcement HTML contains **no exact phrase** — excluded as below threshold; interior zine page may qualify but was not phrase-visible on the fetched URL (deferred to leads).
  - These exclusions demonstrate that **search snippets must not be treated as page-level verification** — a principle strictly applied.

#### Which source families remain underexplored because of paywalls, CAPTCHAs, inaccessible archive search, broken links, JavaScript rendering, missing OCR, or incomplete search indexing

- **Paywall / JS-gated hosts:** **Grammy Weekly** (HTTP 500), **Pop Fantasma** (snippet only, body JS-gated), **Viral Nation** & **PR ON THE GO** (JS/enterprise paywall — snippets but body not fetched) remain partially verified only at snippet level; full body re-verification would require a headless-browser or text-proxy that was not used this pass to keep to lawful, non-circumvention methods.

These require either a **public preview PDF** or a **post-publication contents page** to become verifiable; they are not yet in common-crawl / search indexes at the phrase level.
- **Scanned zine / PDF OCR:** Any zine that is **image-scanned without OCR text layer** would be missed by exact-string text search (phrase not extractable by PyMuPDF/ search indexer). If Coin-Operated interior is image-only, it would be searchable only via OCR — a family deliberately noted as underexplored.

These are not evidence of absence.
- **Regional search depth:** While Spanish/Portuguese SERPs were prioritized and did surface the Indie AM / Shock Web Radio / Pop Fantasma / Rock Culture hosts, **Japanese, Korean, German, French** regional SERPs were logged as attempted but not deeply paged this pass; they remain underexplored but are low-probability for this target’s known geography (Asheville + LatAm press) per dump distribution.

#### Why the final section is a verified public-web inventory rather than proof that no other coverage exists

> **No web search can prove absolute completeness.** Deleted, private, paywalled, print-only, social-only, unindexed, region-restricted, JavaScript-rendered, missing-OCR, or not-yet-crawled content will be missed. This dedicated section is a **verified public-web inventory** through the documented exact-string searches on 2026-09-05, not a claim of complete global publication coverage. It privileges **direct evidence** (fetched HTML/PDF with exact phrase visible, screenshot-capable excerpt, canonical + archive URLs), **accurate classification** (Tier A/B vs. C/D), **useful links** (readable titles, canonical + PDF/issue-index links), and **clear separation** between substantial editorial features and incidental mentions. Independent editorial is not confused with profiles, self-issued releases, or catalog rows; press-release reposts and syndications are clustered, not misrepresented as independent features; duplicates, AMP/print, tracking, RSS and exact mirrors are collapsed. Every “new” item was checked against all prior canonical URLs and duplicate clusters. Archive-only features are clearly labeled (none this pass). No spelling variants, partial names, generic “Zazie” searches, aliases, fuzzy matches or inferred identities were used; every discovery method and exact query is logged, so the work is reproducible.
